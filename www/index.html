AUTONOMOUS AGENT

An AI Copilot that actually browses with you.

Most browser AI extensions are simple text wrappers. Browy's AI Copilot can execute real DOM actions, capture high-resolution viewport snapshots, translate complex pages into any language, and synthesize deep research reports across your open tabs.

Supported Autonomous Directives:

[BROWY_ACTION: TRANSLATE German] [BROWY_ACTION: CLICK Read More] [BROWY_ACTION: FILL search | .net 9 wpf] [BROWY_ACTION: ZOOM 125] [BROWY_ACTION: READER_MODE] [BROWY_ACTION: SCROLL_DOWN]
AiCopilotService.cs — Directives Protocol 
public static AgentActionResult ParseAgentDirectives(string response)
{
    var match = Regex.Match(response, @"\[BROWY_ACTION:\s*([A-Za-z0-9_]+)(?:\s+(.*?))?\]");
    if (match.Success)
    {
        string cmd = match.Groups[1].Value.ToUpperInvariant();
        string arg = match.Groups[2].Value.Trim();
        return new AgentActionResult
        {
            ActionCommand = cmd,
            ActionTarget = arg,
            ActionFeedback = FormatFeedback(cmd, arg)
        };
    }
}

Browy puts privacy first. By default, Browy uses an offline heuristic synthesis engine that never sends any page data to the cloud. If you configure BYOK (OpenAI, Claude, or Ollama), requests are sent directly to your chosen API provider using your own API keys stored securely on your machine via Windows DPAPI.

Browy requires a 64-bit Windows 11 or Windows 10 operating system, the Microsoft Edge WebView2 Evergreen Runtime (pre-installed on almost all modern Windows systems), and .NET 9.0. We also provide a Self-Contained Portable Edition that runs out of the box with zero dependencies.
